# Banking & Credit Operations Platform

Sanitized reference architecture for a Node.js finance application managing credit, debt and related business deals.

## Stack
- Node.js and npm backend services
- Dockerized daily delivery
- 13 websites protected by Cloudflare
- Azure cloud infrastructure
- Azure DevOps and GitHub Actions
- YAML and JSON deployment configuration
- Grafana alerting and Semaphore workflows
- Veeam daily backups and disaster recovery

## Product areas
credit-origination, debt-and-deal-management, customer-portal, document-and-compliance, reporting-and-operations.

This public repository contains no company name, credentials, customer data or production endpoints.
